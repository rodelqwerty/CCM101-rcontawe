
# Laboratory 5: The Cloud Data Engineer

## Mission Overview

After successfully deploying containerized web servers, I was assigned to the Cloud Data Engineering Team at CloudNova Technologies.

Cloud computing involves storing and managing different types of data. Traditional systems commonly use block storage for disk-level data and file storage for shared files, while modern cloud applications often use object storage for unstructured data such as images, videos, and backups. Amazon S3 is a widely used object storage service, and MinIO provides an S3-compatible alternative that can run in a local or cloud-based environment.

In this laboratory activity, I used the KillerCoda Playground to apply my Docker knowledge by deploying a MinIO object storage server. I accessed its web console, created a storage bucket, uploaded sample files, and documented the deployment process.

This activity helped me understand the importance of making cloud storage accessible, organized, scalable, and secure.

## Objectives

By completing this laboratory activity, I was able to:
