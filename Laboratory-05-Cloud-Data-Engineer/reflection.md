# Laboratory 5: Reflection

During this laboratory activity, I learned how object storage works and how to deploy MinIO using Docker. Object storage is better for storing millions of photos because each photo has a unique ID and additional information that makes it easier to find and manage. Unlike traditional block storage, object storage is designed to handle large amounts of files, such as photos, videos, and backups.

Using Docker made deploying MinIO easier because I only needed a few commands to download and run the server. I could also set the username, password, and ports directly in the Docker command. This saved time and made it easier to manage the server. I also learned that a bucket is a container used to store objects such as images and documents. In this activity, I created a private bucket named `client-photos` to store sample files for a photo-sharing application.

I also learned how large companies protect their data from being lost when a server crashes. They can use replication, which means keeping copies of data on multiple servers or locations. They can also use backups to recover important files when problems occur. These methods help keep data safe and available.

Lastly, my confidence in using the Linux command line has improved. At first, I was afraid of making mistakes when entering commands. However, using commands such as `docker pull`, `docker run`, and `docker ps` helped me become more comfortable with the terminal. I still check my commands carefully, but I am now more confident in completing technical tasks. Overall, this activity improved my understanding of cloud storage, Docker, and MinIO and helped me develop skills that I can use in future projects.
