# Checkpoint 4 – Cloud Platform Recommendation Challenge 

## ☁️ Cloud Platform Recommendation Challenge

## 🚀 Client A – Startup Company

### Scenario

> A startup company wants to launch a new mobile application. Their budget is limited, but they expect rapid growth within the next few years.

| Requirement                    | Answer                                                                                                                                                                                                                                                                                            |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Recommended Cloud Platform** | **Google Cloud Platform (GCP)**                                                                                                                                                                                                                                                                   |
| **Recommendation**             | GCP is a good choice because the startup can begin with a small amount of cloud resources and increase them as the application grows. It can help the company avoid spending a lot of money on physical hardware. GCP also provides tools that make mobile app development and deployment easier. |
| **Service 1**                  | **Firebase** – Helps develop and manage mobile applications.                                                                                                                                                                                                                                      |
| **Service 2**                  | **Cloud Run** – Runs applications without needing to manage servers.                                                                                                                                                                                                                              |
| **Service 3**                  | **Cloud Storage** – Stores images, videos, and other files.                                                                                                                                                                                                                                       |
| **Service 4**                  | **Cloud SQL** – Provides a managed database for the application.                                                                                                                                                                                                                                  |

---

## 🎓 Client B – University

### Scenario

> A university already uses Windows Server, Microsoft 365, and Active Directory. The university wants to migrate some services to the cloud.

| Requirement                    | Answer                                                                                                                                                                                                                                    |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Recommended Cloud Platform** | **Microsoft Azure**                                                                                                                                                                                                                       |
| **Recommendation**             | Azure is a good choice because the university already uses Microsoft products. Azure works well with Windows Server, Microsoft 365, and Active Directory. This makes it easier for the university to move existing services to the cloud. |
| **Service 1**                  | **Azure Virtual Machines** – Runs Windows Server in the cloud.                                                                                                                                                                            |
| **Service 2**                  | **Microsoft Entra ID** – Manages users and access to resources.                                                                                                                                                                           |
| **Service 3**                  | **Azure App Service** – Hosts websites and applications.                                                                                                                                                                                  |
| **Service 4**                  | **Azure Storage** – Stores files, documents, and backups.                                                                                                                                                                                 |

---

## 🤖 Client C – AI Research Company

### Scenario

> A research company develops Artificial Intelligence and Machine Learning applications that require high-performance computing.

| Requirement                    | Answer                                                                                                                                                                                                                                                        |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Recommended Cloud Platform** | **Google Cloud Platform (GCP)**                                                                                                                                                                                                                               |
| **Recommendation**             | GCP is a good choice because it provides powerful computing resources for AI and Machine Learning. It supports GPUs and TPUs that can help researchers train AI models faster. GCP also provides tools for building, training, and deploying AI applications. |
| **Service 1**                  | **Vertex AI** – Helps build, train, and deploy AI models.                                                                                                                                                                                                     |
| **Service 2**                  | **Compute Engine** – Provides powerful virtual machines for computing tasks.                                                                                                                                                                                  |
| **Service 3**                  | **Cloud TPU** – Provides specialized hardware for AI and Machine Learning.                                                                                                                                                                                    |
| **Service 4**                  | **Google Kubernetes Engine (GKE)** – Runs and manages applications at scale.                                                                                                                                                                                  |

---

## 🌎 Client D – Global E-Commerce Company

### Scenario

> A multinational online shopping company serves customers around the world and requires highly available infrastructure with automatic scaling.

| Requirement                    | Answer                                                                                                                                                                                                                                                                                       |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Recommended Cloud Platform** | **Amazon Web Services (AWS)**                                                                                                                                                                                                                                                                |
| **Recommendation**             | AWS is a good choice because it provides cloud infrastructure in many locations around the world. It can help keep the online store available even when many customers are using it at the same time. AWS also provides automatic scaling to increase or decrease resources based on demand. |
| **Service 1**                  | **Amazon EC2** – Provides scalable cloud servers.                                                                                                                                                                                                                                            |
| **Service 2**                  | **EC2 Auto Scaling** – Automatically adds or removes servers when needed.                                                                                                                                                                                                                    |
| **Service 3**                  | **Elastic Load Balancing** – Distributes customer traffic across servers.                                                                                                                                                                                                                    |
| **Service 4**                  | **Amazon CloudFront** – Delivers website content quickly to customers worldwide.                                                                                                                                                                                                             |
| **Service 5**                  | **Amazon RDS** – Provides a managed database for the online store.                                                                                                                                                                                                                           |
