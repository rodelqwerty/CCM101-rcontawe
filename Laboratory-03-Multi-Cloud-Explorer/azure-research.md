# Checkpoint 2 – Explore the Three Cloud Platforms 

## Microsoft Azure Research

## Brief Overview

**Microsoft Azure** is a cloud computing platform developed by Microsoft. It provides services for running applications, storing data, managing databases, networking, security, and artificial intelligence.

Azure allows businesses and developers to build, run, and manage applications using Microsoft's cloud services.

## Global Infrastructure

Azure has data centers in many parts of the world. These are organized into **regions**.

* **Regions** are geographic locations where Azure provides cloud services.
* **Datacenters** are facilities that contain the computers and equipment used to provide these services.

Azure's global infrastructure helps organizations provide reliable services to users in different locations.

## Cloud Management Console

The **Azure Portal** is a website used to manage Microsoft Azure services.

Users can use the portal to create, configure, monitor, and manage their cloud resources.

## Four Core Services

| Service                    | Simple Description                                          |
| -------------------------- | ----------------------------------------------------------- |
| **Azure Virtual Machines** | Runs applications using virtual computers.                  |
| **Azure Blob Storage**     | Stores files, images, videos, and other data.               |
| **Azure SQL Database**     | Stores and manages relational databases.                    |
| **Azure Virtual Network**  | Connects and manages communication between Azure resources. |

## Three Advantages

1. **Microsoft Integration** – Works well with Microsoft products such as Windows Server and Microsoft 365.
2. **Global Infrastructure** – Provides cloud services in many locations around the world.
3. **Enterprise Features** – Provides security, identity, and management tools for businesses.

## Enterprise Use Case Scenarios

| Scenario                    | How Azure Can Be Used                                                                          |
| --------------------------- | ---------------------------------------------------------------------------------------------- |
| **Website Hosting**         | A company can use Azure to host its websites and web applications.                             |
| **Virtual Servers**         | Businesses can use Azure Virtual Machines to run applications and servers.                     |
| **Database Management**     | Companies can use Azure SQL Database to store and manage business data.                        |
| **Data Backup**             | Organizations can use Azure services to back up important files and data.                      |
| **Microsoft Integration**   | Businesses can connect Azure with Microsoft products such as Microsoft 365 and Windows Server. |
| **Artificial Intelligence** | Companies can use Azure AI services to create AI-powered applications.                         |
| **Data Analysis**           | Organizations can use Azure tools to analyze and understand business data.                     |
| **Hybrid Cloud**            | Companies can connect their own servers with Azure cloud services.                             |

## Conclusion

Microsoft Azure provides many cloud services that help businesses and developers build, store, and manage applications and data. It is useful for websites, databases, virtual servers, backup, AI, and business applications.
