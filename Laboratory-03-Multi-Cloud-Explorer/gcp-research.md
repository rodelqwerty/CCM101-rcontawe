## Google Cloud Platform (GCP) Research

## Brief Overview

**Google Cloud Platform (GCP)**, also called **Google Cloud**, is a cloud computing platform made by Google. It provides services for storing data, running applications, managing databases, networking, and using artificial intelligence.

Google Cloud allows businesses and developers to use cloud resources without having to manage their own physical servers.

## Global Infrastructure

Google Cloud has **regions and zones** around the world.

* **Regions** are large geographic locations where Google Cloud has data centers.
* **Zones** are separate locations inside a region where cloud resources can run.

This infrastructure helps applications stay reliable and perform well for users around the world.

## Cloud Management Console

The **Google Cloud Console** is a website where users can manage their Google Cloud services and resources.

Users can create **projects** to organize their cloud resources, settings, and permissions.

## Four Core Services

| Service                            | Simple Description                               |
| ---------------------------------- | ------------------------------------------------ |
| **Compute Engine**                 | Runs applications using virtual computers.       |
| **Cloud Storage**                  | Stores files, images, videos, and other data.    |
| **Cloud SQL**                      | Stores and manages relational databases.         |
| **Google Kubernetes Engine (GKE)** | Runs and manages applications inside containers. |

## Three Advantages

1. **Global Network** – Connects applications and users around the world.
2. **Data and AI** – Provides tools for data analysis and artificial intelligence.
3. **Scalability** – Resources can be increased or decreased when needed.

## Enterprise Use Case Scenarios

| Scenario                    | How GCP Can Be Used                                                                     |
| --------------------------- | --------------------------------------------------------------------------------------- |
| **Website Hosting**         | A company can use Google Cloud to host its website.                                     |
| **Data Storage**            | A business can store files, images, videos, and other data in Cloud Storage.            |
| **Database Management**     | A company can use Cloud SQL to store and manage its business data.                      |
| **Data Analysis**           | Organizations can use Google Cloud to study and analyze large amounts of data.          |
| **AI and Machine Learning** | Businesses can use Google Cloud to create AI-powered applications.                      |
| **Container Applications**  | Developers can use GKE to run applications using containers.                            |
| **Application Development** | Developers can build, test, and deploy applications using Google Cloud services.        |
| **Global Applications**     | Companies can deploy applications in different regions to serve users around the world. |

## Conclusion

Google Cloud provides many services that help businesses and developers build, store, and run applications. Its services can be used for websites, databases, data storage, AI, and application development.
