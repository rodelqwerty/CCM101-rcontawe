## Amazon Web Services (AWS) Research

## Brief Overview

**Amazon Web Services (AWS)** is a cloud computing platform provided by Amazon. It offers services for running applications, storing data, managing databases, networking, security, artificial intelligence, and application development.

AWS uses a **pay-as-you-go pricing model**, which means organizations pay for the cloud resources they use instead of buying and maintaining physical servers.

## Global Infrastructure

AWS has cloud infrastructure in many parts of the world. It is organized into **Regions** and **Availability Zones (AZs)**.

* **Regions** are geographic areas where AWS provides cloud services.
* **Availability Zones** are separate locations within an AWS Region.
* Using multiple Availability Zones helps applications stay available and reliable.

AWS's global infrastructure allows organizations to provide services to users in different locations around the world.

## AWS Management Console

The **AWS Management Console** is a website used to manage AWS services and resources.

Users can use the console to create and manage cloud resources, monitor applications, check billing information, and access different AWS services.

## Four Core AWS Services

| Service        | Simple Description                                      |
| -------------- | ------------------------------------------------------- |
| **Amazon EC2** | Runs applications using virtual servers.                |
| **Amazon S3**  | Stores files, images, videos, backups, and other data.  |
| **Amazon RDS** | Stores and manages relational databases.                |
| **Amazon VPC** | Creates a private and secure network for AWS resources. |

## Three Advantages

1. **Scalability** – Resources can be increased or decreased when needed.
2. **Global Infrastructure** – AWS provides cloud services in many locations around the world.
3. **Pay-as-you-go Pricing** – Organizations pay for the resources they use.

## Enterprise Use Case Scenarios

| Scenario                    | How AWS Can Be Used                                                                         |
| --------------------------- | ------------------------------------------------------------------------------------------- |
| **Website Hosting**         | A company can use AWS to host websites and web applications.                                |
| **Data Storage**            | Businesses can use Amazon S3 to store files, images, videos, and backups.                   |
| **Database Management**     | Companies can use Amazon RDS to store and manage business data.                             |
| **Application Development** | Developers can use AWS to build, test, and deploy applications.                             |
| **Data Analysis**           | Organizations can use AWS services to analyze large amounts of business data.               |
| **Artificial Intelligence** | Businesses can use AWS AI and machine learning services to create intelligent applications. |
| **Disaster Recovery**       | Companies can use AWS to create backups and recover applications after system failures.     |
| **Cloud Migration**         | Organizations can move their existing applications and servers to AWS.                      |

## Conclusion

Amazon Web Services provides many cloud services that help businesses and developers build, store, and manage applications and data. AWS is useful for websites, databases, storage, application development, AI, backup, and cloud migration.
