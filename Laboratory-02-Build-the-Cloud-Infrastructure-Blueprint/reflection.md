# Checkpoint 7 – Mission Reflection

This laboratory helped me understand the basic parts of cloud infrastructure and how they work together. I think compute resources are the most important because they provide the processing power needed to run applications and services. However, compute also needs storage to save data and networking to connect users and systems.

Linux supports cloud computing because it is commonly used to run servers and applications. During this laboratory, I used Linux commands to check the operating system, CPU, RAM, storage, and network information. This helped me understand how a server works and how its resources can be checked using the terminal.

Technical documentation is important before deploying infrastructure because it helps organize information and explain how the system will work. Good documentation also makes it easier to find problems, make changes, and understand the system in the future. Creating the cloud architecture diagram and Markdown files helped me organize what I learned.

During this laboratory, I learned how to use basic Linux commands, identify cloud infrastructure components, compare AWS, Azure, and GCP services, create a simple cloud architecture diagram, and write technical documentation using Markdown. I also learned how to use Git and GitHub to organize and manage my laboratory files.

My GitHub portfolio improved because I added a complete cloud computing project with documentation, screenshots, and an architecture diagram. This project shows that I can use Linux, GitHub, Markdown, and basic cloud concepts. Overall, this laboratory gave me a better understanding of cloud computing and helped me become more confident in using Linux and cloud technologies.
