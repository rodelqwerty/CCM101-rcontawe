# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced the basic Linux environment
and cloud computing workflow using KillerCoda.

## Objectives

- Access a cloud-based Linux environment.
- Explore the Linux operating system.
- Gather system information.
- Organize files and directories.
- Create a GitHub repository.
- Document technical work using Markdown.

## Activities Performed

1. Accessed Ubuntu using KillerCoda.
2. Created the Linux user `rcontawe`.
3. Added the user to the sudo group.
4. Gathered system information.
5. Created the laboratory directory structure.
6. Created Markdown documentation.
7. Created a GitHub repository.
8. Uploaded the laboratory files.
